# PX4 1.16.2执行器测试实现摘要

## 用途

本页保存为Nano单电机测试选择MAVLink命令时使用的源码核对结论。完整PX4源码副本体积接近1 GB，整理后不再保存在测试目录中。

## 已确认实现

PX4 1.16.2的Commander处理`VEHICLE_CMD_ACTUATOR_TEST(310)`，参数含义如下：

| 参数 | 含义 |
|---|---|
| `param1` | 归一化输出值；8%为`0.08` |
| `param2` | 超时秒数；小于等于0时发布释放测试控制动作 |
| `param3`、`param4` | 当前流程填0 |
| `param5` | MAVLink输出功能；1～4对应Motor1～Motor4 |
| `param6`、`param7` | 当前流程填0 |

Commander会将Motor1功能映射到内部执行器功能101，并将超时转换为毫秒。超时为0或大于3000 ms时，内部上限按3000 ms处理。

混控输出模块收到`actuator_test`后临时覆盖对应输出；到达`timeout_ms`后在模块内部退出测试模式。这个内部超时不会重新发布一条“已清除”的`actuator_test`消息，因此不能通过第二次读取旧topic来判断清除。

## 实机结果

- MicoAir PX4 1.16.2对`MAV_CMD_DO_MOTOR_TEST(209)`返回`UNSUPPORTED`。
- 对命令310的clear、start和release-control均返回`ACCEPTED`。
- QGC观察到`action=1`、`function=101`、`value=0.08000`、`timeout_ms=2000`。
- 接4S后的M1实测转动并停止，其余三路静止。

因此当前脚本固定使用310，不自动回退209。
