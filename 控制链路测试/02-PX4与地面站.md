# 02 PX4 与 QGroundControl

前置：[[01-实物与供电核验]]。下一步：[[03-ELRS与MTF]]。

## PX4 1.16.2 升级后的重建顺序

已确认固件为 `MICOAIR_H743_V2 / PX4 Release 1.16.2 / default`。升级后的首轮配置只使用USB供电，拆除桨叶，不接动力电池、MTF-02P和LicheeRV Nano。

1. 在QGC参数页使用“工具 → 将所有参数恢复默认值”，等待飞控重启并重新连接。不要导入PX4 1.15.2整包参数。
2. 在“机架”页选择与实物一致的通用四旋翼X布局并应用、重启。若电机臂布局或飞控箭头方向尚未确认，先停在此处拍照核对，不能靠软件图标猜测。
3. 设置飞控板方向。以PCB箭头相对机头的真实方向为准；AIO是否以45度安装取决于实际装机方向，不能仅凭板型名称直接填写旋转参数。
4. 当前飞控尚未固定上机，用户优先验证通信和控制链路。正式水平校准、最终安装方向复核和控制效果调整延后到飞控固定后进行；现阶段只需确认IMU在线、姿态变化方向正确且没有持续硬件故障。
5. 当前顺序改为：ELRS/CRSF输入 → RC失联识别 → MTF-02P消息 → LicheeRV Nano MAVLink → 无桨电机响应。执行器测试保持无桨，并放在链路和保护检查之后。

### 本阶段验收

- [x] PX4 1.16.2与`MICOAIR_H743_V2`硬件目标匹配。
- [ ] 参数恢复默认并正常重启。
- [ ] 通用四旋翼X机架已选择。
- [ ] 飞控箭头和机头方向有照片或文字记录。
- [ ] 陀螺仪、加速度计、水平面校准完成且QGC无对应红色告警。
- [ ] 重启后姿态地平仪随实物俯仰、横滚方向正确。

## 执行顺序

1. 拍照/导出原始固件信息与参数备份。45A AIO 的微空手册给出 PX4 target `micoair_h743-v2`，从 PX4 1.16.0 起有官方支持。先核对板上丝印，再选择固件；无需刷写时保留现有可用版本。
2. USB 连接 QGC。记录固件版本、板名、传感器状态与电池读数；拔插两次确认能稳定重连。
3. 设定四旋翼机架类型与安装方向，桌上轻微俯仰/滚转/偏航，检查 QGC 姿态方向与实物一致。45A 手册提示 AIO 按 45° 安装，实际方向以实物与配置一致为准。
4. 做 IMU 水平/加速度计校准；按实际硬件设置电池监测。保存参数文件，记录修改前后值与重启是否生效。
5. 确认 QGC 能看飞控消息、状态告警，并可导出日志。此阶段保持未解锁，不接电机主电源。

## 通过标准

- [ ] QGC 识别的板级 target、固件版本与实物一致。
- [ ] 姿态变化方向正确，无持续传感器故障；参数重启后仍在。
- [ ] 有固件信息截图、原始/当前参数备份、校准记录。

若 USB 反复断开，先查数据线、接口和供电；若姿态方向不对，先查板安装角和坐标配置，禁止进入电机阶段。
