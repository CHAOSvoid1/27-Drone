# 06 PX4 → ESC → 1404-4500KV 电机

前置：[[01-实物与供电核验]]、[[02-PX4与地面站]]，建议先完成 [[03-ELRS与MTF]]。下一步：[[07-端到端联调]]。

> [!warning] 执行条件
> 四个桨叶全部拆除；电机牢固固定；主电池/电源电压同时满足 AIO 与电机额定范围；旁边可立即断电。**不得为通过测试而关闭解锁检查、RC 失联保护或电机测试保护。**

## 执行

### 当前已通过的配置门禁

```text
SYS_AUTOSTART = 4001
CA_ROTOR_COUNT = 4
PWM_MAIN_FUNC1..4 = 101, 102, 103, 104
PWM_MAIN_TIM0 = -4（DShot300）
COM_MOT_TEST_EN = 1
BAT1_N_CELLS = 4
BAT1_V_DIV = 21.12
```

`BAT1_SOURCE=-1`表示电池监测仍被禁用。读取结果为`BAT1_A_PER_V=40`、`BAT1_I_CHANNEL=-1`、`BAT1_V_EMPTY=3.20`、`BAT1_V_CHARGED=4.20`。两个通道的`-1`表示采用板级默认ADC通道，电芯阈值也适用于当前4S锂电池。45A AIO手册给出的PX4电压与电流系数分别为`21.12`和`14.14`，因此旧配置中的电流系数40不沿用。接4S前设置`BAT1_SOURCE=0`和`BAT1_A_PER_V=14.14`，保存、重启并复查参数。

1. 断电焊接/连接四路三相电机，核对每路三相没有短路到机架或相邻通道。记录 M1–M4 的物理位置。1404-4500KV 仅描述电机，不决定本阶段电池节数。
2. QGC 中选对应四旋翼机架与输出映射，核实 AIO 电调是 **AM32 45A**。45A 官方手册建议从 `DShot300` 开始；当前固件与实物不一致时暂停、核对电调配置。PX4 下不先启用双向 DShot。
3. 先连接 USB 看 QGC，再接主电源。检查 ESC 启动状态和有无异常温升。PX4/QGC 的 Actuators 测试页，逐路启用滑块，只让**一个电机**以最低可稳定转动输出短时旋转；立即回到停转。按 M1→M4 逐个记录“屏幕通道—实物电机—方向”。
4. 若通道不对应，先断电再改输出映射；若方向不对应，按 ESC 支持方式反向或交换两根相线，再重复。连续高速运行不在本轮范围内。
5. 验证点击停转和QGC退出测试后电机都停止。本阶段只用QGC逐路Actuator Test打通PX4→ESC→电机，不进行已解锁闭环控制。
6. Nano→PX4控制链在未解锁状态通过uORB消息验证；机架和测试架完成前不把非零Offboard闭环直接接到电机，避免固定台架上的速度误差造成控制器持续加大输出。

## 2026-09-29电池检测结果

4S接入后PX4输出：

```text
voltage_v: 16.22653 V
ocv_estimate: 16.24839 V
remaining: 86.5%
connected: True
cell_count: 4
source: 0
warning: 0
faults: 0
current_a: 1.28659 A
current_average_a: 15.00000 A
```

判定：电池来源、4S节数、电压、连接状态和告警正常，电池检测主门禁通过；仍需把16.23 V与充电器/电池检测器读数对照。`current_average_a`是PX4用于长期平均/续航估计的滤波字段，15 A并非当前瞬时电流；`current_a`才是当前采样值。低负载下1.29 A可能包含电流传感器零点误差，当前不据此做精度判定，后续用外部电流计校准。确认无异常发热、异味和重启后，可进入QGC逐路无桨电机测试。

## 2026-09-29四路无桨电机测试：通过

QGC Actuator Testing逐路测试结果与PX4 Quad X示意完全一致，无异常：

| PX4编号 | 实物位置（机头朝上） | 转向组 |
|---|---|---|
| M1 | 右前 | 逆时针组（蓝） |
| M2 | 左后 | 逆时针组（蓝） |
| M3 | 左前 | 顺时针组（绿） |
| M4 | 右后 | 顺时针组（绿） |

四路均能响应并停止，编号和旋向无需修改。至此`PX4 → DShot300 → AM32 ESC → 1404电机`执行器链通过；结合此前Nano到PX4内部目标的验证，两段控制链均已分别打通。
