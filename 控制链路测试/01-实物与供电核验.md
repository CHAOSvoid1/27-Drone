# 01 实物与供电核验

返回 [[00-测试总览]]；通过后进入 [[02-PX4与地面站]]。

## 准备

- [x] 拍 AIO 正反面和包装标签，复核用户提供的 **45A AM32** 型号、焊盘丝印、现有固件、ESC 固件。45A 官方手册写 3–6S（约 10–27V）；实物不符时不要接主电池。
- [x] 查 1404-4500KV 电机、ELRS 接收机、Lichee 供电和 GC4653 模组各自额定电压；记录已有电池的节数与实测电压。电机 KV 不能代替额定电压说明。**若电机不允许 3S 或更高，本 AIO 不进入电机测试。**
- [x] 建立接线表：电源正负、飞控 5V/12V、UART TX/RX/GND、相机排线 Pin 1 方向、四个电机的三相焊点。为每根线拍照编号。
- [x] 四个桨叶全部拆除。电机与 AIO 固定在绝缘台架，电源切断方式随手可及。

## RM2027规则专项门禁

- [ ] 建立重量预算，目标整机不超过200 g并保留规则变更余量。
- [ ] 建立100×100×100 mm包络模型；所有工作状态均不得超出最终适用尺寸。
- [ ] 设计全包围桨叶保护罩，任何方向观察均无桨叶和机体危险部位外露。
- [ ] 选用柔性桨叶并记录型号、材料、质量和最高允许转速。
- [ ] 保留独立ELRS紧急停桨链路；Nano不得覆盖急停动作。
- [ ] 每次旋转/悬停测试指定一名安全员，明确口令、断电点和人员站位。
- [ ] 正式规则发布后复核最大供电容量、工作电压、裁判系统和最终尺寸重量公式。

## 执行

1. **完全断电**时测 VBAT 正负极是否短路；目视检查桥锡、碳纤维接触、线序和极性。先不要连接 Lichee、相机、MTF 或 ELRS。
2. USB 单独给飞控上电：观察有无异常温升、异味、反复重启。记录电脑识别的设备与 QGC 能否发现飞控。
3. 只有在型号、电池与电机供电范围都确认后，使用与实物匹配的主电源。首次上电优先限流电源或 smoke stopper；测 VBAT、5V 和需使用的其他稳压输出。不要用 AIO 的 12V 图传口给 5V 外设。
4. 单独给 Lichee 上电并确认启动，再确认 UART 信号电平和需要的电源余量；不要先把 Lichee 的供电脚并到 AIO 5V。若用独立稳压器，后续 UART 连接仍需共地。
5. 对 GC4653 排线按模组 pinout 核对接口宽度、Pin 1、供电电压和 MIPI lane；禁止按“同为 22Pin”直接插。

- [x] USB与4S主电源上电无异常；PX4读取16.23 V、4节、无告警和故障。
