# 控制链路测试目录说明

## 当前结论

截至2026-10-03，以下链路已经实测打通：

`Nano脚本 → UART1 / MAVLink → PX4 → MicoAir H743 V2 AIO 45A → M1电机`

实物测试条件为拆桨、飞控Disarmed、4S供电、M1输出8%约1秒。M1正常转动并停止，M2～M4未误动作，脚本结果为`FULL_PASS`。

## 目录结构

| 位置 | 内容 | 使用方式 |
|---|---|---|
| `00-测试总览.md` | 项目阶段、结论和下一步 | 首先阅读 |
| `01`～`08`编号文档 | 修正后的正式测试流程 | 按编号查阅，不记录聊天式排障过程 |
| `脚本/实机链路` | 已用于真实硬件的程序和部署脚本 | 当前主要使用 |
| `脚本/通信诊断` | MAVLink观察、环境检查和pymavlink维护 | 链路异常时使用 |
| `脚本/SITL仿真` | Nano命令源和PX4 SITL桥 | 只连接仿真，不连接真实执行器 |
| `测试记录` | 当前有效的综合记录和端到端通过记录 | 保存实测证据 |
| `测试记录/历史归档` | 早期初始化、排障和审查过程 | 仅追溯时阅读 |
| `测试记录/附件` | 与记录对应的图片等证据 | 不直接执行 |
| `测试备份` | 参数备份和Nano离线安装包 | 恢复环境时使用 |
| `参考资料` | 从外部源码核对得到的结论摘要 | 查询协议实现 |
| `工具` | 与主控制链路无关的小工具 | 按对应流程使用 |

## 当前推荐入口

1. 查看`00-测试总览.md`了解整体进度。
2. 查看`07-端到端联调.md`了解Nano到电机的已验证流程。
3. 实机链路复测只使用`脚本/实机链路/部署Nano电机测试.ps1`和`nano_motor_test.py`。
4. 后续视觉控制开发从`04-Lichee与MAVLink.md`、`08-AirSim硬件在环与定位方案.md`继续。
