# 05 GC4653视觉链路测试流程

前置：[[04-Lichee与MAVLink]]。下一步：[[06-无桨电机测试]]。

## 1. 相机基础检查

1. 断电安装GC4653排线并确认方向。
2. 启动Nano，停止可能占用ISP的旧程序。
3. 运行镜像自带`sensor_test`，确认GC4653、MIPI、ISP初始化成功。
4. 导出一帧YUV并复制到电脑，按NV21、2560×1440转换为PNG检查颜色、亮度和几何方向。
5. 正常退出程序，确认ISP与内存释放；重复启动三次。

## 2. 连续采集

1. 连续运行相机至少10分钟。
2. 记录实际帧率、丢帧、内存、温度和异常日志。
3. 分别测试明亮、普通室内、弱光和运动模糊场景。
4. 确认曝光变化时画面不会长时间黑屏或严重偏色。

## 3. NPU与识别

1. 用镜像自带模型验证CV181x运行时和NPU可执行。
2. 使用任务模型时记录输入尺寸、量化方式、类别、置信度阈值和模型版本。
3. 对固定目标测试检出率、误检率、首次检出距离和连续跟踪稳定性。
4. 统计从取帧到输出目标坐标的端到端延迟，而不是只记录模型推理时间。
5. 输出统一目标消息：时间戳、目标类别、置信度、框中心、框尺寸和图像尺寸。

机架完成前不要求完成真实目标精度测试。先用固定图片、录制样帧或人工生成的目标框建立统一接口，使后续模型只需替换“目标检测”模块，不改飞控通信和控制状态机。

正式识别算法尚未确定时，使用`mock_target`代替模型输出。最小字段包括：`timestamp`、`valid`、`class_id`、`confidence`、`center_x`、`center_y`、`box_width`、`box_height`、`image_width`、`image_height`。模拟输入只进入日志、未解锁飞控或SITL，不连接真实电机执行。

## 4. 与飞控联调

1. 视觉程序只读取相机并输出目标消息，不直接解锁飞控。
2. MAVLink链路稳定后，在未解锁状态把人工目标偏差转换为受限的非零速度指令，读取PX4的`trajectory_setpoint`核对数值与方向。
3. 验证视觉超时、相机断开和程序崩溃时，控制输出立即失效。
4. 完成日志对时，确保图像、识别结果和飞控消息可以按时间戳对应。

## 通过标准

- [x] GC4653能初始化并导出可查看样帧。
- [x] 镜像自带NPU和YOLO示例可运行。
- [ ] 人工目标框/录制样帧能输出统一目标消息。
- [x] 受限非零MAVLink速度目标已由PX4在未解锁状态正确接收；待把人工目标框接到该接口。
- [ ] 目标消失、图像超时或程序退出后停止更新控制目标。
- [ ] 相机连续运行10分钟无崩溃或持续丢帧。
- [ ] 任务模型完成实际目标数据集验证。
- [ ] 端到端视觉延迟满足30秒任务链路预算。
- [ ] 真实模型的精度、距离和运动模糊测试在机架/测试环境完成后执行。
