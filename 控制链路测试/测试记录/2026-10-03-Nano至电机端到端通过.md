# Nano至电机端到端实测通过

## 目标

验证`Nano脚本 → UART1/MAVLink → PX4 → AIO电调 → 电机`的真实执行链路。

## 配置

- 飞控：MicoAir H743 V2 AIO 45A
- 固件：PX4 1.16.2，`MICOAIR_H743_V2`
- Nano串口：`/dev/ttyS1 @ 115200`
- 命令：`VEHICLE_CMD_ACTUATOR_TEST(310)`
- 电池：4S，测试前15.89 V
- 状态：拆桨、机体固定、飞控Disarmed、无failsafe
- 目标：Motor1，8%，约1秒

## 结果

| 检查项 | 结果 |
|---|---|
| 电池门禁 | 通过，4节且已连接 |
| clear命令 | `ACCEPTED` |
| start命令 | `ACCEPTED` |
| stop命令 | `ACCEPTED` |
| M1实际转动 | 是 |
| M1完全停止 | 是 |
| M2～M4误动作 | 无 |
| 脚本退出 | `exit_code=0` |
| 最终结论 | `FULL_PASS` |

报告关键字段：`protocol_accepted=true`、`battery_verified=true`、`physical_motor_observed=true`、`physical_stop_observed=true`、`other_motors_stationary=true`、`fault_reason=null`。

## 结论与边界

真实执行链路已经打通。该结果验证直接执行器测试通道，不等同于Offboard位置控制、姿态控制、动态控制分配或飞行状态下的失联策略已经通过。
