## 系统版本

```bash
NAME=Buildroot
VERSION=-gd4003f15b
ID=buildroot
VERSION_ID=2023.11.2
PRETTY_NAME="Buildroot 2023.11.2
```

| 字段        | 值                    | 含义                                                                                     |
| ----------- | --------------------- | ---------------------------------------------------------------------------------------- |
| NAME        | Buildroot             | 系统名称。这里是 Buildroot                                                               |
| VERSION     | -gd4003f15b           | 版本补充信息。Git 提交哈希前缀，表示构建时源码所处的提交点；前面为空说明没有额外版本描述 |
| ID          | buildroot             | 系统唯一标识符，小写，供脚本判断系统类型用（类似 ubuntu、centos）                        |
| VERSION_ID  | 2023.11.2             | Buildroot 的版本号，格式为 年.月.补丁，即 2023.11 系列的 2 号维护版本                    |
| PRETTY_NAME | "Buildroot 2023.11.2" | 供人阅读的完整名称，带引号是因为含空格                                                   |
