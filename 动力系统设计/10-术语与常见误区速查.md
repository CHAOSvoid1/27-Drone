# 10 术语与常见误区速查

## 1. 常用术语

| 术语     | 含义               | 容易混淆的地方               |
| ------ | ---------------- | --------------------- |
| KV     | 电机速度常数，常用rpm/V   | 不是功率，也不是额定转速          |
| $K_T$  | 转矩常数，常用N·m/A     | 与KV近似成反比，但要注意电机和电流定义  |
| RPM    | 每分钟机械转数          | eRPM还需要除以极对数才能得到机械RPM |
| S      | 电池串联节数           | 决定电压，不直接决定容量          |
| P      | 电池并联支路数          | 增加容量和供流能力             |
| mAh    | 电荷容量             | 不能单独表示能量或最大电流         |
| Wh     | 标称能量             | 更适合比较不同电压电池的储能        |
| C数     | 以容量倍数表示的标称放电率    | 标签值不等于无压降的真实持续能力      |
| ESC    | 电子调速器            | 除了调速，还负责换相、制动和部分保护    |
| 桨径     | 桨叶旋转圆直径          | 对推力、功耗和桨盘面积影响很大       |
| 桨距     | 理想每转前进距离的几何描述    | 不是实际每转飞行距离            |
| 静推     | 零来流或台架静止时的推力     | 不能直接代表高速前飞推力          |
| 推重比    | 最大总推力与重量之比       | 必须说明对应电压和持续时间         |
| $C_T$  | 无量纲推力系数          | 随桨、转速、雷诺数和前进比变化       |
| $C_P$  | 无量纲轴功率系数         | 不等于包含ESC/电机损失的输入功率系数  |
| 前进比$J$ | 来流速度相对桨尖尺度的无量纲参数 | 悬停静推时$J=0$            |
| 电压下沉   | 负载电流导致端电压下降      | 会同时影响转速、推力和飞控供电安全     |

## 2. 常见误区

### 误区一：KV越高，电机越有力

KV描述速度常数，不直接描述功率或最大推力。高KV电机配大桨和高电压可能首先遇到过流、压降和过热。

### 误区二：KV乘电压就是飞行转速

$KV\times V$只给出理想空载转速尺度。带桨后需要转矩，实际转速会因绕组压降、ESC损耗和电池压降明显下降。

### 误区三：50%油门等于50%推力

油门是控制输入，推力取决于实际RPM。即使RPM与命令近似线性，推力也通常更接近RPM的平方关系。

### 误区四：三叶比双叶多一片，所以推力乘1.5

增加叶片会改变实度、诱导损失和电机工作点。必须使用该桨自身的数据，不能按叶片数线性缩放。

### 误区五：电池C数乘容量就是一定能长期输出的电流

这是标签给出的理论值或厂家规定值。真实可用能力还受内阻、温度、老化、插头、导线和允许压降影响。

### 误区六：更大容量一定飞得更久

更大容量通常也更重，会增加悬停功率。应把电池质量加入整机后重新计算，而不是只比较mAh。

### 误区七：推重比大于1就适合飞行

大于1只代表理论上可能离地。姿态修正、爬升、抗风和低电量降落都需要额外推力余量。

### 误区八：最大静推能够直接预测最高速度

前飞时桨叶工作在非零前进比，推力会变化；最高速度还受倾角、机体阻力、桨距速度和可用功率限制。

### 误区九：ESC标称电流大于单电机最大电流就一定安全

还必须检查四合一ESC的总热能力、环境散热、短时/持续定义、电池线和接插件能力。

### 误区十：厂家同系列电机的数据可以互相代用

不同KV、不同绕组和不同版本可能具有不同电阻、电流限制和效率。台架表只有在电机、桨叶、电压和测试条件匹配时才能直接使用。

## 3. 阅读参数表时的四个问题

看到任何性能数字时，先问：

1. 使用的具体电机和桨叶是什么？
2. 电压是满电电压、标称电压还是测试中的实际端电压？
3. 数据是瞬时值、短时值还是热稳定后的持续值？
4. 推力、电流、RPM和温度是否在同一个测试点同时记录？

如果这四项无法回答，该数字最多只能用作候选筛查。
