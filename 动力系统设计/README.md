# 多旋翼无人机动力系统常识与设计基础

## 文档目的

本组文档是一套面向初学者和项目成员的通用知识笔记，介绍电动多旋翼动力系统的基本概念、常用公式、参数关系和验证方法。它不依赖某一种机架、电机或飞控，也不以某个赛季方案作为前提。

主要回答以下问题：

- 电机、ESC、电池和桨叶各自决定什么；
- KV、电压、转矩、电流、转速、推力和功耗如何关联；
- 怎样从整机质量和任务需求反推动力系统；
- 哪些公式可用于初步估算，哪些结论必须通过台架测试获得；
- 怎样避免“只看KV”“只看C数”“把三叶推力直接乘1.5”等常见错误。

本文以电动多旋翼为主。固定翼推进、直升机旋翼和涵道风扇有部分共通知识，但不能直接套用全部结论。公式主要用于理解关系和初步筛查，不能替代指定电机、桨叶、电压组合的台架数据。

## 先记住的六条常识

1. KV表示转速常数，不表示电机功率，也不表示电机质量好坏。
2. 电机、桨叶、电压和ESC必须作为一个组合评价，不能孤立选型。
3. 桨径对推力和功耗影响很强；允许时，大桨低转速通常比小桨高转速更有利于悬停效率。
4. 电池的mAh表示电荷容量，Wh更适合比较能量，C数只给出理论放电能力。
5. 油门百分比不等于推力百分比，满电性能也不等于任务末段性能。
6. 公式负责缩小候选范围，最终结论依靠同组合台架数据和整机测试。

## 最重要的设计原则

> 动力系统设计不是分别选择“最强电机、最大C数电池和最大桨叶”，而是在质量、尺寸、推力、响应、效率、温升、航时和供电能力之间寻找可验证的平衡。

完整链路为：

```text
电池化学能
→ 电池端电压与电流
→ ESC开关调制
→ 电机电磁转矩和转速
→ 桨叶气动力
→ 整机推力、姿态力矩和飞行速度
```

任意一环过载都会限制整套系统：

- 电池内阻过大：电压下沉，转速和推力下降；
- ESC额定不足：过热、限流或损坏；
- 电机与桨不匹配：过流、效率低、磁钢或绕组过热；
- 桨叶过大或桨距过高：负载和功耗急剧上升；
- 推重比不足：只能勉强离地，无法可靠抗扰；
- 机体过重或迎风面积过大：航时和速度同时恶化。

## 公式使用约定

| 符号 | 含义 | 常用单位 |
|---|---|---|
| $V$ | 电压 | V |
| $I$ | 电流 | A |
| $P$ | 功率 | W |
| $E$ | 能量 | Wh或J |
| $n$ | 每秒转数 | rps |
| $RPM$ | 每分钟转数 | rpm |
| $D$ | 桨直径 | m |
| $\rho$ | 空气密度 | kg/m³ |
| $T$ | 推力 | N |
| $Q$ |转矩 | N·m |
| $C_T$ | 推力系数 | 无量纲 |
| $C_P$ | 功率系数 | 无量纲 |
| $J$ | 前进比 | 无量纲 |

除特别说明外，计算必须使用SI单位。工程中常说的“100 g推力”实际是100 gf，换算为力：

$$
100\,gf=0.100\times9.80665\approx0.981\,N
$$

## 证据等级

本文将结论分为四级：

| 等级 | 依据 | 用途 |
|---|---|---|
| A | 同电机、同桨、同电压的可信台架数据 | 可以用于选型 |
| B | 自己按规定工况完成的台架测试 | 可以用于最终确认 |
| C | 无量纲公式或相近组合外推 | 只用于筛查 |
| D | 经验比例或网络口述 | 只能形成待验证假设 |

最终选型至少需要A级或B级证据。
